# Keepa-亚马逊-商品详情 API 参考

路径：`/keepa/productRequest`；请求方式：POST；参数放入 SCM 代理的 `params`，不是外层字段。

来源：[LinkFox 官方文档](https://agent-files.linkfox.com/skills/_tools_matrix/api-docs/tools/keepa.md)；核对日期：2026-11-03。

以下为当前请求参数契约。未填的选填参数保留为空缺，不猜默认筛选；参数中的 false、0 与空值有不同含义。

- **积分消耗**：按动态规则计费：消耗积分 = 0.045 × 本次商品详情查询消耗的 Keepa token。

## 请求参数

POST Body（JSON）：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| asin | string | 是 | — | 亚马逊标准识别号（ASIN），多个 ASIN 用英文逗号分隔，最多 5 个，最大长度 300 字符。示例：`B0088PUEPK` 或 `B0088PUEPK,B00U26V4VQ,B07M68S376` |
| domain | string | 是 | — | 亚马逊域名 ID：`1`（美国）、`2`（英国）、`3`（德国）、`4`（法国）、`5`（日本）、`6`（加拿大）、`8`（意大利）、`9`（西班牙）、`10`（印度）、`11`（墨西哥）、`12`（巴西）。 |
| history | integer | 否 | `0` | 返回值是否包含历史数据、历史销量；`1` = 包含价格历史、销售排名、历史销量等时间序列数据，`0` = 仅返回基本商品信息。 |
